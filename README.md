# مكتب عاطف وهبة للخدمات العامة

مشروع Android أصلي بـ Kotlin وJetpack Compose، بواجهة عربية RTL وتخزين محلي دائم عبر قاعدة بيانات Room.

## تش��يل المشروع

1. افتح المستودع في Android Studio حديث يدعم Android Gradle Plugin 8.7.3.
2. استخدم JDK 17، ثم نفّذ Gradle Sync.
3. شغّل تطبيق `app` على جهاز أو محاكي Android (الحد الأدنى Android 8.0 / API 26).

## المنفذ في هذه المرحلة

- واجهة عربية RTL بهوية داكنة مع لمسات زرقاء وذهبية.
- لوحة تحكم تقرأ عدد العملاء وإجمالي المعاملات ورصيد الخزينة والأقساط غير المسددة من Room.
- إضافة العملاء والبحث بالاسم أو الهاتف.
- إدارة منتجات البازار وأسعار الشراء والبيع والمخزون مع تنبيه بصري للكمية المنخفضة.
- تسجيل معاملات الخدمات وإيصالات القبض والصرف بأرقام مرجعية تلقائية.
- تخزين المبالغ بوحدة القرش لتقليل أخطاء التقريب.
- مخطط بيانات قابل للتوسع للخدمات المعرفة من المدير، الموظفين، العقود والأقساط، العمولات، رصيد التسويق، التوصيل والإعدادات.
- ترحيل Room إضافي من الإصدار 1 إلى 2 يحافظ على بيانات الجداول الحالية ويضيف الجداول الجديدة.

## حدود مهمة

هذه مرحلة تنفيذ عملية وليست بعدُ نظامًا محاسبيًا كاملًا جاهزًا للإنتاج. العقود والأقساط والموظفون والعمولات والتوصيل موجودة كبنية تخزين أولية، وتحتاج واجهات تشغيلية واختبارات حسابية وتدفق اعتماد/صرف قبل استخدامها ماليًا. الخزينة محلية على الجهاز وليست متزامنة أو احتياطية سحابيًا. يلزم اختبار المشروع والبناء على Android Studio قبل النشر، ومراجعة محاسب لمسارات الضرائب والأقساط والإيصالات. لا تُدخل بيانات حقيقية حساسة قبل إعداد النسخ الاحتياطي والتحكم في الوصول.

## سياسة الحسابات

- تخزن الأسعار والمبالغ بوحدة القرش (عدد صحيح من نوع `Long`).
- القيم الافتراضية التي تم إعدادها للإصدار القادم: فائدة تقسيط 10%، ضريبة 5%، عمولة تسويق 0.9%.
- يتم حفظ أساس الضريبة كنص إعداد، لكن منطق احتساب واعتماد العقود غير مفعّل حتى الآن؛ لذلك لا تعتمد على قاعدة البيانات الحالية لحساب ضريبة أو قسط فعلي.
