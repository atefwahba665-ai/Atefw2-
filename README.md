# مكتب عاطف وهبة للخدمات العامة

مشروع Android أصلي بـ Kotlin وJetpack Compose، بواجهة عربية RTL وتخزين محلي دائم عبر Room.

## تشغيل المشروع

1. افتح المستودع في Android Studio حديث يدعم Android Gradle Plugin 8.7.3.
2. استخدم JDK 17، ثم نفّذ Gradle Sync.
3. شغّل تطبيق `app` على جهاز أو محاكي Android (الحد الأدنى Android 8.0 / API 26).

## الموجود حاليًا

- واجهة عربية RTL بهوية داكنة مع لمسات زرقاء وذهبية.
- لوحة تحكم أولية مرتبطة ببيانات Room.
- إضافة العملاء مع إنشاء كود تلقائي مبني على رقم السجل.
- إضافة المنتجات والأسعار والمخزون.
- مخطط قاعدة بيانات محلية للعملاء والمنتجات ومعاملات الخدمات والمدفوعات؛ تُخزّن المبالغ بوحدة القرش لتجنب أخطاء الفواصل العشرية.
- أقسام أولية للعملاء والبازار والخدمات والمالية.

## حدود النسخة الحالية

هذه نقطة انطلاق قابلة للبناء والتوسعة وليست بعدُ نظامًا محاسبيًا كاملًا جاهزًا للإنتاج: واجهات العقود والأقساط والإيصالات والخزينة والموظفين والعمولات والتقارير والنسخ الاحتياطي والمزامنة وتسجيل الدخول والصلاحيات لم تُنفّذ بعد. البيانات محلية على الجهاز وليست متزامنة بين عدة مستخدمين. لم تُرفق صورة شخصية في الطلب المتاح، لذلك يظهر حاليًا رمز نصّي AW بدل صورة أو شعار نهائي. يجب إضافة اختبارات وتدقيق محاسبي وأمني قبل اعتماد التطبيق للاستخدام التجاري الفعلي.
